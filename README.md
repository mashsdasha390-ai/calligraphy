# Каллиграфия

Локальный HTML/CSS/JS сайт, макет 1440 px. Фон #E2CFCF, Lora из assets/fonts.
Откройте index.html.

Оригиналы работ подключены из assets. Пока обложка, круговая работа и упражнение полууставом используют фрагменты reference-v2.jpg: отдельных совпадающих файлов в assets нет.
Подписи появляются при наведении или фокусе с клавиатуры; на сенсорных устройствах видны постоянно.
Слова из одной и двух букв связаны со следующим словом неразрывным пробелом в HTML.
Треугольник мягко пульсирует с периодом 2.6 с, останавливается при наведении/фокусе и ведёт к введению.
Анимации учитывают prefers-reduced-motion. Форма демонстрационная, отправка не подключена.
Предыдущая версия сохранена в .v2-backup.

Мобильная версия: до 800 px. Вертикальная композиция с чередующимися отступами, видимые подписи, форма с полями 16 px и высотой от 48 px. Проверено в браузере при 320, 390, 768 и 1440 px. Пользовательский текст в index.html сохранён.
